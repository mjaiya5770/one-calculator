How it works

The calculator reads whole expressions, not just one operation at a time: it follows the standard order of operations (brackets, powers, then × and ÷, then + and −), understands implied multiplication like 2π or 3(4+1), and treats % as "divide by 100". Trig functions use degrees by default — tap the Deg key to switch to radians. Ans inserts your last answer, and the memory keys (MS, MR, MC, M+, M−) work like a physical calculator. Solvers and homework sites charge for step-by-step answers; here the full expression engine is free.

Results use standard double-precision math. For exam-critical work, double-check rounding on very long decimals.

Method & worked example

Method: Your expression is broken into tokens and evaluated with standard precedence: brackets first, then factorials and % (percent divides by 100), then powers, then × and ÷, then + and −. Implicit multiplication works too, as in 2π, and trig functions use degrees unless you switch to radians.

Worked example: 2 × (3 + 4)² = 98 — the brackets give 7, the power gives 49, then the multiplication. Also try sin(30) = 0.5 in degree mode, and 5! = 120.

When to use this

  • A homework or lab expression chains several operations — a root, a power and a trig function — and a four-function calculator keeps losing your place.
  • You need a logarithm or an inverse trig value that a basic calculator simply does not have a key for.
  • You are working at a keyboard and typing the whole expression is faster than tapping buttons between steps.
  • A long calculation needs an earlier answer reused, or a value parked in memory while you work out another part.

How to use it, step by step

  1. Type the whole expression in the box, or build it with the keypad keys — function keys insert the function name and its opening bracket for you.
  2. Check the angle mode before any trig: it starts in Degrees, and the Deg key switches it to Radians.
  3. Press Enter or the equals key to evaluate; the answer appears in the results and becomes Ans for the next expression.
  4. Use MS to store a value you will need again, MR to recall it, and M+ or M- to adjust it — MC clears it.
  5. Click any line on the history tape to load that expression back into the box and rerun or edit it.

Another worked example

In Degrees mode, type log(10000) + sqrt(81) * sin(90) and press Enter. The parts resolve in order: log(10000) is 4, sqrt(81) is 9 and sin(90) is 1, so the multiplication contributes 9 and the displayed result is exactly 13. It is a good self-check for the mode setting, too — run the same expression in Radians mode and the sine term changes completely.

Frequently asked questions

How do I type a calculation from my keyboard?

Click the expression box and type naturally — for example 2+3*4, sqrt(144), or ln(e). Function names (sin, cos, tan, asin, acos, atan, ln, log, sqrt, abs), the constants pi and e, and the postfix keys ! and % are all supported. Press Enter to calculate.

What is the difference between ln and log?

ln is the natural logarithm (base e ≈ 2.718), used across science and finance. log here is base 10, the "common" logarithm — log(1000) = 3.

How do factorials work here?

Type a number then ! — 5! = 120. Non-integers work too, using the gamma function, so 0.5! ≈ 0.886. Negative whole numbers are not defined and return an error.

Does the calculator remember anything between visits?

No. The history tape and memory live only in this page, in your browser, and vanish when you close the tab. Nothing is sent to a server.

Why does sin(90) not equal 1 on my calculation?

Because of the angle mode. In Degrees mode sin(90) is 1, as school geometry expects; switch to Radians mode and the same keystrokes read 90 as 90 radians, giving about 0.893996663601. Neither answer is wrong — they are answers about different angles — so check the Degrees or Radians label above the keypad before trusting any trig result.

What does Ans actually hold, and when does it change?

Ans holds the result of your last successful calculation, and typing ans in an expression inserts that number — handy for feeding a root or a logarithm into the next stage of a problem. It updates every time a calculation succeeds, starts at 0 when the page loads, and is not kept when the tab closes.
