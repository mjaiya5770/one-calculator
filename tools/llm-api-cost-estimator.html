How it works

Cost per request = (input tokens × input price + cached input tokens × cached price + output tokens × output price) ÷ 1,000,000. Daily cost is per-request cost × requests per day; monthly uses 30 days and yearly 365. The comparison table reprices your exact workload on every model, which is the only honest way to compare — a model with cheap input but expensive output wins on summarization and loses on generation. Caching matters because a repeated system prompt or document can be served at the cached-input price: on GPT-5 that is a 90% discount on the cached share.

Estimates only, from published list prices as of November 2026 — providers change prices and run promotions, and your bill will also reflect retries, failed calls and any minimums. The words-to-tokens rule (≈0.75 words per token) is an English average; code, JSON and non-English text tokenize less efficiently.

Formula & worked example

Formula: Cost per request = (fresh input tokens × input price + cached input tokens × cached price + output tokens × output price) ÷ 1,000,000 — prices are per 1M tokens. Daily = per request × requests per day; monthly = daily × 30; yearly = daily × 365. Tokens from words: tokens ≈ words ÷ 0.75 for typical English.

Worked example: GPT-5 at 2,000 input and 500 output tokens per request: (2,000 × $1.25 + 500 × $10.00) ÷ 1M = $0.0075 per request. At 1,000 requests a day that is $7.50 a day, $225.00 a month, $2,737.50 a year.

How to use it, step by step

  1. Pick the model you are costing — the table reprices all six regardless.
  2. Enter input tokens per request (or type a word count and let the converter fill it).
  3. Enter output tokens — be honest; this is the expensive side of the bill.
  4. Set the cached share if you reuse a system prompt or document across calls.
  5. Enter requests per day and read per-request, monthly and yearly costs.
  6. Compare the same workload down the model table before committing to a flagship.

Frequently asked questions

How much does GPT-5 cost for 1,000 requests a day?

At 2,000 input and 500 output tokens per request: $0.0075 per request, $7.50 a day, about $225 a month. The same workload on GPT-5 mini is $0.0015 per request — $45 a month. Output tokens dominate: they cost 8× the input price on GPT-5.

Why are output tokens so much more expensive than input?

Input is processed in one parallel pass; output is generated one token at a time, each step re-running the model. Every provider prices that difference in — output runs 4–8× the input price on current flagship models. Shortening outputs is usually the biggest single saving available.

How many tokens is a page of text?

A typical page is about 500–600 words, and at ≈0.75 words per token that is roughly 700–800 tokens. Ten pages of source material pasted into every prompt is about 7,333 tokens of input per request — which is why long-context habits get expensive fast.

What does prompt caching actually save?

If 80% of your input is a repeated system prompt or document, the cached share is billed at the cached price — $0.125 instead of $1.25 per 1M on GPT-5. On a 10,000-token input that is 8,000 tokens at the cached rate, cutting the input cost of each request by about 72%.

Is a cheaper model always the better deal?

Only if it finishes the job in one call. A mini model that needs two retries or a second verification pass can cost more than one flagship call. Compare cost per successful task, not cost per request — run both on your real workload with the comparison table here.

Do these prices include batch discounts?

No. Batch APIs (OpenAI Batch, Anthropic Message Batches, Gemini batch mode) typically cut prices by about 50% in exchange for asynchronous processing within 24 hours. If your workload is not interactive, halve the figures here as a first approximation and confirm on the provider page.

How do I estimate tokens for a document I paste into every prompt?

Count its words and divide by 0.75 — a 6,000-word policy document is about 8,000 tokens. If it rides along on every request, caching that block is usually the single biggest cost cut available, at 90% off the cached share on GPT-5 pricing.

Why does the same app cost more on Claude than on GPT-5 here?

At these list prices, Sonnet's input ($3.00) is 2.4× GPT-5's ($1.25) and its output ($15.00) is 1.5× ($10.00). Price is only half the comparison, though — if one model resolves the task in a single call and the other needs a retry loop, the retry loop is the real price.
