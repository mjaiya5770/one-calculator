How it works

The generator builds a character pool from the types you select, then picks each character using crypto.getRandomValues() — a cryptographically secure random source built into your browser. Longer pools and longer passwords mean exponentially more combinations for an attacker to guess.

Method & worked example

Method: Passwords are drawn with the browser's cryptographic random source (crypto.getRandomValues), never a predictable seed. Each position is picked at random from the character sets you switch on, and the length is clamped between 8 and 64 (20 by default). Strength grows as length × log₂(pool size).

Worked example: With all four sets on, the pool is 88 characters — 26 uppercase + 26 lowercase + 10 digits + 26 symbols — so a 20-character password carries about 129 bits of entropy (20 × log₂ 88 ≈ 129).

When to use this

  • A new account deserves better than a reused password, and you need a strong one in the next ten seconds.
  • A site insists on symbols, or forbids them, and the password has to fit that rule set exactly.
  • You are setting up a password manager and generating a fresh, unique password for each account as you add it.
  • A shared household or team login needs a long password nobody has to be able to pronounce or remember unaided.

How to use it, step by step

  1. Slide the length control to the size you want — the slider runs from 8 to 64 characters and starts at 20.
  2. Tick the character types the account allows: uppercase, lowercase, numbers and symbols. At least one type must stay ticked.
  3. Press Generate — a fresh password is drawn in your browser each time, so press again if you want another candidate.
  4. Use the Copy button, paste the password straight into the account form and your password manager, and check the copy message appears.
  5. Never reuse the same generated password on a second site; generating a separate one costs one more click.

Another worked example

A settings walkthrough, because the output is random by design: set the length slider to 16, leave uppercase, lowercase and numbers ticked, and untick symbols — a common setup for sites that reject symbol characters. Every password those settings produce is exactly 16 characters long, and every character comes only from the 62 characters in the three ticked sets: 26 uppercase letters, 26 lowercase letters and 10 digits. No symbol can appear, no character outside those sets can appear, and the exact password is different each time you press Generate.

Frequently asked questions

How long should my password be?

At least 16 characters for important accounts; 20+ is better and costs you nothing when a password manager fills it in for you. Length beats complexity — a long simple password outlasts a short tricky one.

Should I use a password manager?

Yes. A password manager lets you use a unique 20+ character password on every site without memorizing any of them. Popular options include Bitwarden (free), 1Password, and Apple's built-in keychain.

Why do symbols matter?

Symbols expand the character pool from 62 to 90+ characters, multiplying the total combinations. More importantly, they help you meet complexity requirements on sites that demand them.

Does this page send or store the password it makes?

No. Generation happens locally in your browser: the code builds the password on your device using the browser's cryptographic random source, crypto.getRandomValues, and the generate step makes no network call and saves nothing. The password exists only in the box on this page until you copy it somewhere safe — close the tab without copying and it is gone.

Does the generator promise at least one character from every type I tick?

No, and it is worth knowing: each position is picked at random from the combined pool of all ticked sets, with no guarantee step afterwards. A short password with all four types ticked can occasionally come out with, say, no symbol in it — if a site demands one, press Generate again, or lengthen the password, which makes a missing type very unlikely.

What happens if I untick every character type?

There is no pool left to draw from, so instead of a password the box shows the message: Select at least one character type. Tick any one set — even numbers alone will generate — and the button works again, though a single-set password should be made much longer to stay strong.
